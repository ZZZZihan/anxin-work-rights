# 法规采集与复现

本目录保存 8 部法律、行政法规、部门规章/规范性文件及司法解释的官方全文来源，选取 54 条与欠薪和劳动关系确认相关的原文条款。标注由 Agent 完成，尚未经法律专业人员核读。

## 离线复核

从仓库根目录运行：

```sh
python3 data/labor-public-v1/curation/laws/collect.py --verify-clean
```

该命令不访问网络。它校验冻结 HTML 字节的 SHA256，用 Python 标准库 HTMLParser 提取原文块，按 `selection.json` 中经检查的段落索引去除导航/分享/页脚，再重新计算 `clean/` 全文、`sources.json` 和 `laws.json` 并逐字比较。清洗只统一空白及删除页面外壳，不替换法律用语或标点；长条文的列举项和续款均通过段落引用保留。

```sh
python3 data/labor-public-v1/curation/laws/collect.py
```

上面的默认离线命令从同一组冻结原文和 `selection.json` 重新生成文件。`--inspect` 可输出所有可见块及其原始索引。`--fetch` 才会请求网络，使用明确的官方 URL；已存在且内容变化的快照拒绝覆盖，要求重新核读和冻结，不自动套用旧索引。任何来源刷新失败都会保存失败日志并非零退出，不继续重建，以免把旧快照可用误报为刷新成功。HTTP 元信息只保存 URL、状态、字符集、字节数、时间、摘要，不保存 Cookie 或凭据。

## 日期与版本范围

- `sources.published_on` 是页面明示的网页发布日期；法规 `issued_on` 是正文或官方元数据明示的公布/成文日期。工资支付暂行规定页面未单独明示网页发布日期，因此留空。
- `effective_on` 表示所录版本的施行日。劳动法和劳动合同法的该字段留空，因为保存的全文页未单独载明相应修正决定施行日；其末条载明的原法施行日 1995-01-01、2008-01-01 分别保存在 `original_effective_on` 中。版本沿革和这一限制见每条记录的 `status_note`。
- 2005 年通知只披露文号及落款，未单独披露施行日，因此 `effective_on=null`。
- 2025 年司法解释（二）第二十一条明确：司法解释（一）第三十二条第一款同时废止，此前解释与解释（二）不一致的以解释（二）为准。2020 年来源全文保留历史公布文本供审计；选取条款不含已经明确废止的第三十二条第一款。
- 本次核读证明保存了指定官方文本并准确引用了条款，不证明已查尽截至采集日的全部修订、清理、地方实施规则、冲突适用或个案溯及力。

## 免费访问与复用边界

各页面可免费公开访问，无需登录或付费；这不是开放许可声明。`usage_note` 保存复用限制，源站页面的版权/使用条款与规范性文件原文应分别核对。2025 年解释（二）最终使用最高人民法院官网权威发布页面，其新闻正文后附完整 21 条司法解释；正文部分和条款部分均由原始快照提取，未把新闻解读作为法条。

最高人民法院公报的解释（二）全文地址在普通 HTTP 和 HTTPS 直取中均出现 302 重定向循环；河南省高级人民法院候选页面直取连接拒绝。没有绕过这些站点限制，也没有使用搜索摘要拼接全文；最终使用普通请求成功取得的中央官网正式附文。济南中院候选页脚另有未经书面允许不得转载信息内容、建立镜像的声明，其快照仅留在本机临时目录，不包含在最终数据集。首次失败的真实时间和错误见 `fetch_failures.json`，其他候选失败见 `acquisition_notes.json`。
