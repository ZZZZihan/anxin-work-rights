# 公开资料扩充与检索基线验证

本次从 `78ed96aae8c694d72d1de5de55b223a9816ff835` 增加公开数据覆盖、独立编写的检索题和可重放报告。没有调整 production 检索排名，也没有调用大模型。本记录是本地整合验证与独立 Agent 技术复核，部署和用户验收另计。

## 数据与题集

- 公开案例从14组增至33组；原14个案例对象、4个既有案例来源记录、旧原始字节、HTTP元数据与清洗文本逐项比较未变。新增19组来自既有冻结汇编及2个最高法官方新来源。
- 发布数据包含14个来源、1641段来源文本、8份法规及54条选定条文、38项材料描述。没有取得证据原件。数据指纹为 `94593cc65bc34e1d739f22b6a66c95e19ff768e083f435bada899fc86309ac8e`。
- 4例日期直接取自公开裁判结果；29例日期与全部33例地区留空。12例属于执行、破产、调解或协商等程序，其限制已随运行检索引用返回。
- 128题包括94道案例检索、24道条文检索、10道域外题；dev 88题、test 40题。题集 SHA-256 为 `8f246287cc124d0d2da8007f84fd0d6bb8a2a5031c88a03cd0cea0fdadf027c0`。
- 标注 Agent 先读来源、写题、定分组，没有运行检索或查看排名。整组修正3道工资支付规定题的 split，消除多 gold 跨法带来的隐性泄漏；旧题面、gold及其余字段保持不变，初始/修订题集与变更说明保留在 [history](../../../data/labor-eval-v1/history)。

## 初始观测

检索函数仅接收 `query` 与统一 `limit=6`，与当前 HTTP 入口一致。topic、gold、rationale、split 和题型不进入检索。使用同一生产模块及冻结索引，未复制另一套检索算法。

| 范围 | 命中至少一个标注目标 | MRR@6 | 域外空返回 |
| --- | --- | --- | --- |
| 全部正例 | 46/118，39.0% | 0.216525 | — |
| dev正例 | 29/82，35.4% | 0.179675 | — |
| test正例 | 17/36，47.2% | 0.300463 | — |
| 域外题 | — | — | 8/10；dev 6/6，test 2/4 |

基线保留全部失败：72题没有命中已标注目标，另外3题只命中部分标注目标，2道域外题误返回资料。未标为 gold 的其他记录也可能相关，不能据此报告 precision 或法律回答错误率。返回的4632次段落引用结构检查通过，只说明其原文和来源一致，不代表语义论证成立。

完整分母、每题返回、失败及输入/实现/依赖哈希见 [baseline.json](../../../data/labor-eval-v1/baseline.json)，可读表格见 [baseline.md](../../../data/labor-eval-v1/baseline.md)。所有来源仍在检索库中，dev/test是任务分组，不能称为未见文档或未见法律知识测试。

三个子Agent分别负责案例加工、独立题集标注、独立技术复核，请求配置均为 `gpt-6.1-sol / ultra`；未独立核验每个子会话实际运行配置。Agent核读与技术复核不等于法律专业审核。当前数据量、抽样方式和有限正例标注不支持真实用户效果、胜诉率、法律准确率或企业生产可用性结论。
