# Pure rule baseline v1

标准库 Python 实现，无训练、无模型调用、无外部请求。入口为
`rules.predict(record) -> dict`，也可运行 `python3 rules.py INPUT.jsonl`。

只读取输入中的用户消息和 `tool_state`。`id`、`labels`、`category`、
`family` 及其他字段均不参与预测；不从助手发言抽取金额事实。

规则按自然语言的日期、应发/实付语义和金额归属累积事实。金额先以
`Decimal` 解析，再转 JSON 数值；月薪、日薪或单价不推算成期间总额，
非工资款排除，未知不能按零处理。明确纠正覆盖旧事实，未调和的多个
候选作为冲突。达到超时重试上限时优先返回 `report_tool_failure`。

## 能力边界

这是小型可解释语言规则。它能覆盖明确日期、期间总额、工资付款与
报销拆分、明确零值、部分常见冲突和多轮纠正，但不保证理解任意话术。
复杂跨句付款清单、隐含年份、日期重述中未明确说明金额是否沿用、
复杂嵌套否定等仍可能造成保守追问或错误。规则没有 OCR、检索、法律
资格认定、工资制度计算或真实多轮服务能力。
