# 冻结源码补充复核

当前未发现阻塞基线运行的评测基础设施问题。冻结清单17项均逐一与当前文件SHA-256核对一致；9项评分/合同测试和21项规则行为测试共30项由独立审查方再跑通过，另有6个评分对抗探针通过。完整证据与哈希见同名JSON。

rules.predict仅读取messages及tool_state，不读取id、labels、category、split或gold文件，不进行网络请求、模型加载或训练。唯一文件读取位于可选CLI入口，读取调用方显式指定的输入。规则未通过ID或场景表查答案；所给单测也直接覆盖修改ID/额外标签不改变结果。

规则行为边界仍需用留出结果说明。它依赖中文正则与邻近语境，对未显式说不完整的自然付款叙述倾向当作完整，这比严格要求独立完整性确认更弱；助手消息不被用来建立事实。上述是冻结基线的方法限制，不能据此修改已运行测试后的规则或提示词。不能把30项通过推广为留出样本正确，或推广为生产可用。

确定性指标区分严格JSON、合同结构、动作、缺项/冲突、工具参数与问题字段覆盖。问题field正确并不能证明问题文字正确；已用故意字段/文字不匹配的探针确认该盲点被明确标成未评分。后续独立审阅实际输出中的全部提问文字及全部失败样本，才可报告文字语义结论。

尚待核对：匿名打乱的输出包、实际Qwen守护遥测及退出证据。审查方没有执行模型推理、付费API调用或训练。
