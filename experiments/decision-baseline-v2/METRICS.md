# 新留出集配对比较预声明

在实现者读取新留出内容和任何新集推理前冻结本文件、提示词、控制器、运行器、评分器、测试及 v1 依赖哈希。作者只读旧业务合同，另一位 Agent 检查新标签；先完成数据修正和封存再推理。全是合成情境，非真实投诉记录、法律专家标注或外部团队盲测。用于观察这一小批样本的行为，不推断生产准确率。

四臂为相同新 72 条的 Qwen-v1、Qwen-v2、DeepSeek-v1、DeepSeek-v2。原 v1 提示词/合同/评分器不变；v2 是提示词、结构协议、程序控制的组合变更，不做组件独立因果归因。旧 v1 失败知识已用于开发，新留出标签/内容不参与开发。

- 全 72 条的规范决策正确数：动作、missing/conflict 分类、问题字段、工具参数全匹配。问题文字另外审查。v2 必须通过真实 dispatcher，失败不算成功。
- 相同 64 条非耗尽情境上比较两协议，排除程序直接接管的收益。另列 8 条耗尽状态；v2 无模型调用，计程序控制正确，绝不计模型正确。
- 原始 JSON 合法率和协议接受率：只用实际模型调用数为分母。跨臂 neutral JSON 判定拒绝围栏、重复键、非有限数、非对象；精度由各自协议另管。v1 原解析器 strict 字段只保留为历史诊断，不冒充统一指标。
- v1 仅复演算术；v2 调用真实本地 Decimal 算术。只统计本实验控制器的状态语义；不声称网站 API、分布式服务或用户下一轮已接通。
- 独立动作诊断：按原始输出显式动作、问题字段和工具参数，忽略冗余分类元数据/空键，用统一 v1 诊断器。v2 为分析转成动作壳；不得用于执行、修改保存输出或规范决策得分。单列问题文字审查后才叫业务语义正确。
- 所有输出的问句盲审，审查包隐藏后端和协议臂；结构风格仍可能暴露。检查是否真正询问缺失/冲突事实、是否要求核实而非选择喜欢的答案、是否无已知信息重复和错误前提。多个字段问题须全部合格。不依赖独立问句审查的非追问样本由确定评分器核验。
- 配对统计只在同一模型、同一新输入上数 win/loss/tie；报告按 group 两条均对的数目。小集不作统计显著或泛化优越性声明。
- 请求失败、截断、缺失结果保留在计划 72/64 分母内。没有自动重试、改写或换模型。若单独恢复执行，另列且不能覆盖首次结果。
- 参数相同：温度 0、关闭 thinking、最多 512 输出 token、每题上下文复位、串行请求、只用提示词要求 JSON；无强制解码和修复模型。v2 提示词较长，单列输入/输出 token、调用时延和跳过次数；不能把旁路的零时延计入模型速度。
- DeepSeek 使用供应商别名，记录返回型号、fingerprint、usage；价格仅为官方公布价估算，非账单。Qwen 记录固定模型文件校验、MLX 包版本及内存守卫。

独立问句审查先完成再写报告。发现新集问题时保留初次结果并披露，不能用新集调提示词后继续把它称独立测试。后续改动另建新评测集。
