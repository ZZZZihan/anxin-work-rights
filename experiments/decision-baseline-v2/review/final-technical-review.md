# v2 独立技术复核结论

正式封存版未发现剩余技术阻塞。已独立验证 27 个源码和 6 个数据文件的完整清单及全部哈希；输入、标签与独立逐条审查版一致。当前冻结版 68 项单元与集成测试全部通过。审查未请求模型/API、未训练、未写源码或数据。

另有 31 项早期独立协议/控制器反例，以及 26 项独立 runner/scorer 反例全部通过。后 26 项涉及的业务源码与正式冻结版相同，之后只有 freeze.py 的括号修正。68 项正式测试覆盖最终整合版本。测试只出现合成 HTTPError 对象的清理提示，没有失败。

## 已核对的关键行为

- 可信状态严格限定，耗尽状态在模型请求前短路；非法状态阻断。次数在工具执行前记录，上限为两次，无自动重试。
- 拒绝提案不调用工具；分发重新解析原始内容并检查提案/规范输出；金额先以 Decimal 验证原始数字精度。
- 真实本地 Decimal 工具及返回结构严格核对；失败、超时、取消状态留存。同会话成功复用、参数改变拒绝及并发中的重复请求有独立反例覆盖。
- 推理只接收 allowlist 内的 messages/tool_state；标签、分组、类别和解释不进入提示。实际成功评分必须具有一致规范输出、准确结果、合法次数、无错误和无复用证据。
- 四臂同 72 条、相同 64 条非耗尽分别计分，8 条程序短路单列。缺失和请求失败仍留在计划分母；配对组与单条组分别统计。原始模型动作诊断与可接收系统输出分开，语法与协议接受分开。
- v1 解析/提示/评分依赖保留；新的共同原始 JSON 指标拒绝围栏、重复键和非有限数，不把旧解析器的宽松行为冒充统一口径。

## 数据审查与范围

已逐条审查 72 条输入与标签，共 36 组，30 条调用、34 条追问、8 条失败；34 条金标问句已按真实未决事实复核。0 项未解决标签问题。作者只读旧业务合同，精确输入载荷与旧 train/dev/test 重复各为 0；这不证明语义上的完全独立。数据全部为 Agent 创作的合成情境，不是真实投诉、专家金标或外部团队盲测。

工具控制只限单个 Python 对象生命周期；未实现持久化、分布式幂等恢复或强制终止超时函数。评估是提示、协议和程序控制的组合对比，不能独立归因某组件，也不能推断生产准确率。当前结论不包含网站接入、部署或用户验收。

匿名实际输出问句语义审查仍待主 Agent 提供审查包；在该审查前，字段匹配不能表述为问句业务语义正确。审查者没有打开带后端身份的四臂实际结果。
