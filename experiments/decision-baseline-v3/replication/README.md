# 网络中断后的独立完整补充运行

主运行 DeepSeek 在连续3次运输错误后按预设停止，原始35行及缺失分母保留在 ../results/deepseek 和主报告中。端点恢复可达后，注册一次完整72条重跑以观察模型实际行为；不是选择性重试失败样本，也不拼接成功答案。模型、prompt、事实、解析/评分、参数和两臂程序完全沿用冻结版本，没有基于答案修改。该追加运行是在主运行中断后决定，属于明确标注的补充证据，不能声称为原先预注册主运行。Qwen结果只以相对链接复用，不重新采样。

独立匿名审查后执行 `python3 -B experiments/decision-baseline-v3/replication/reproduce.py --check`，使用同一冻结报告算法复现本目录成绩。registration.json在追加API请求前绑定原失败结果与适配器代码。最多追加一轮，若仍有失败仍保留计划分母。
