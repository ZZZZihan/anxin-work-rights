## 固定生成设置

- Qwen：`mlx-community/Qwen3-32B-4bit`，revision `bcaaf7f538adf166c1080a2befdb4f6019f66639`；不加载 adapter。每份文书独立进程、greedy、seed 123、non-thinking、输出最多 4096 tokens、总长最多 12288、prefill 128、4 bit KV / group 64 / start 0。模型载入记录应与 model-identity.json 一致，权重验证沿用全哈希回执并核查当前 stat 指纹。
- MLX：allocator guideline 24 GiB（不是严格分配上限）；wired 容量固定 20 GiB并回读；cache 512 MiB。生成 context 不再覆盖为设备推荐的 51.84 GiB。压力 critical 即停、warning 持续 10 秒即停、相对该进程启动 swap 增长超过 4 GiB即停，外部监测覆盖加载和预填充，单文书绝对时限 600 秒。保持这些保护，不通过放宽阈值完成样本。

- DeepSeek 使用临时回环 SSH 转发到现有测试机出口。TLS 在本机建立，SNI/Host 固定 `api.deepseek.com`，证书校验启用，密钥不复制到测试机；不改全局 DNS/hosts，不跟随 HTTP 重定向。隧道结束后关闭。

## 请求、停止和预算

每份文书最多一次 HTTP POST；仅 HTTP 发送前允许最多三次连接尝试，建连 timeout 10 秒，退避 0.5/1 秒。证书错误不重试。socket 超时 120 秒，父级单请求绝对时限 180 秒，整批绝对时限 2400 秒。所有发送之后的失败都不再 POST；发送开始但返回失败时，是否计费保持未知。认证/参数类 HTTP 错误停止；累计三次请求错误停止。成功返回后无论答案差、带 Markdown、格式错、空内容或 length 截断，都不重采样。

每次计划请求先按 UTF-8 字节+1024 作为输入 token 保守上界，按峰值 input $1.32/M、output $3.96/M 与满额 4096 输出预扣预算；单批最多 $2。当前官方定价在 2026-10-17 查核：<https://api-docs.deepseek.com/quick_start/pricing/>。保存 token usage 和峰值估算，不能把估算称为账单；真实账单未查询。诊断与正式费用分别记录，不拼接成功答案。
