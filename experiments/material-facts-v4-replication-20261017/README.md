# 运行修复后的同批公开材料复测

2026-10-17，规则、Qwen3-32B-4bit、DeepSeek 各完成同一批九份材料，全部正常 stop。没有训练或加载 adapter。旧 95 个文件字节不变，正式批次启动前冻结 108 项代码、数据和协议摘要。本轮是已揭晓材料复测，不是新盲测。

## 正式结果

九份行政文书节选、167 项暂定金标，原始文本、提示和评分不变。basic 比较类型和值，strict 再比较对象、期间、限定词和陈述属性；一对一匹配，遗漏和整份协议失败均保留分母。F1 是匹配统计，不是法律正确率。

| 后端 | 正常返回 | 原协议有效 | accepted basic TP/FP/FN；F1 | accepted strict TP/FP/FN；F1 |
|---|---:|---:|---|---|
| 规则 | 9/9 | 9/9 | 5/1/162；5.78% | 0/6/167；0% |
| Qwen | 9/9 | 0/9 | 0/0/167；0% | 0/0/167；0% |
| DeepSeek | 9/9 | 5/9 | 70/19/97；54.69% | 32/57/135；25.00% |

三者完整文书全对均为 0/9。Qwen 没有正式接受项，precision 为 null；零 F1 不能解释为模型完全不理解材料。其九份都有 Markdown 外围栏，一份另含非法 JSON 转义。DeepSeek 三份外围栏，另一份 42 项超过 40 项上限。DeepSeek 正式逐项拒绝数 1 不包括整份协议拒绝造成的丢弃。

## 运行修复与限制

Qwen 的 MLX-LM 生成 context 原来会覆盖 wired 设置；项目进程内替换后回读 20 GiB，未改全局安装包，保留原压力、swap 与超时保护。单改设置仍失败的 dev 诊断已经保存；用户授权正常退出应用后再运行，不能把成功只归功于代码。正式九份独立进程耗时合计 856.139 秒（约 14.27 分钟），MLX peak 最大 17.838 GiB，全部压力采样为 1，swap 增长 0。已有 swap 未清空，wired/allocator guideline 都不是整个进程的硬内存上限。

DeepSeek 本机直连复现 TLS EOF，临时使用既有测试机出口完成九次连接、九次 POST，全为首次成功，无重复采样。TLS/证书和密钥仍在本机与官方域名之间处理，隧道结束后关闭。正式进程约 90.495 秒；本机直接出口未被证明永久修复，重跑仍依赖测试机可达。详细诊断见 [RUNTIME_REVIEW.md](RUNTIME_REVIEW.md)。应用服务指向新 runtime；默认不会自动建立隧道。
