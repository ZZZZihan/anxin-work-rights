# 本机网页验收

2026-10-17，真实内嵌浏览器，`http://127.0.0.1:3014/#evidence`，本机开发环境，服务固定 rules。非部署、非用户人工验收、非模型成绩。

1. 浏览器创建“本地验收·合成单位”，API仅负责上传明确标识的合成文字及启动文字读取；后续提取、阅读候选、范围确认、金额确认与计算均由浏览器操作。
2. 原文应付1000/1200元显示冲突，已付未知保持空白。用户填写劳动者、单位、完整工资期间及核实说明；逐条阅读候选后解释取舍并确认1000元。已付未确认时计算按钮禁用（browser-unknown-blocked.png）。
3. 用户显式填写已付0元并说明为合成核实场景，勾选完整性与核对依据；点击计算生成1000.00−0.00=1000.00及D1回执。该操作是模拟用户确认，不是模型判断。
4. 输入已付修订草稿并勾选后，通过同一认证用户API模拟另一会话撤回应付；后台轮询读到新版本，计算消失、全部核对勾选清空、草稿文字仍在（browser-revision-invalidated.png）。
5. 另一案件导入真实官方公开文书的脱敏摘录（来源和字节记录见browser-public-setup.json）。浏览器提取返回3418.87元候选及原文块/位置；该金额没有填入确认栏，范围和已付仍未知，计算禁用（browser-public-source.png、browser-public-candidate.png）。这份材料是公开文书文字，不是工资流水原件或OCR图像。

验收没有根据公开材料伪造用户的完整金额确认，没有提交法律申请、训练或生产数据。页面上的候选“字面支持通过”不表示语义已判对。截图保留本机测试案件名称与场景说明。
