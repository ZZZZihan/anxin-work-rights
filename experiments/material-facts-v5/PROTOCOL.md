# 新公开材料上的事实表示 v2 评测协议

本轮跟踪 Issue #38，修复个人/群体金额、单笔/完整已付、签约/工作日期的表示与消费。没有训练、adapter、RL 或模型权重修改。旧 v4 及运行修复复测的原始输入、标签、提示和结果全部保留。

## 数据与隔离

目标为 3 份开发材料、8 份全新留出材料，由独立作者从官方公开文书选择必要节选。以案件及关联工程分组；同案转载不可跨 split，且与 v4 全部 12 份不重叠。来源清单、获取方式、版本、原始响应摘要和节选定位保留。公开浏览不等于训练/再分发许可；本轮只做小批推理评测，原整页保存在本机，不入库。

数据作者与独立审查者在模型运行前核查目标事实覆盖、引文、语境、未知金额、单位、主体和日期角色及接受备选。标签是暂定研究标注，不是法律专家裁定。实现者只用开发材料调试，正式冻结之前不读取留出具体答案。freeze.json 生成后不得改输入、标签、提示、协议、校验器或评分；改变时必须建立另一轮，不能挑选本轮成功项。

## 共同候选协议

只抽取与工资争议有关的金额和日期候选，使用 schemaVersion=2，最多 40 项。每项显式记录主体作用域、金额/日期含义、完整性、计价单位、所属工资期间及陈述属性；所有模型共用相同消息。subject指金额享有/收取方或日期所述当事人，不自动取付款方。日期只包括工资、任职、合同、支付和直接影响金额的实质日期，不抽取纯受理、立案、公布或救济期限；依程序生效/送达触发的相对履行期限不抽取，明确日历日期的实际、约定或责令支付截止日为payment_date。同一句同一主体同一角色并列的多个日期区间以完整连续原文为一项，不同事件/角色分别提取；未登记的等义粒度差异仍可能影响严格评分。保留原文精度，不补齐年份或缺失端点；金额不从欠付和已付反推总额。

接受纯 JSON 或恰好包裹整个 JSON 的一个 `json`/无语言 Markdown 围栏，原始回答与格式转换类型永久保留。不得搜索正文中的片段 JSON、修内部转义、补字段、截断候选或再次调用模型修复。外层格式兼容属于本轮正式生产协议，另行报告原生纯 JSON 比例。字段、枚举、跨字段约束、引文位置和金额原文值仍严格校验。未知金额保持 null，不变成 0。

个人总额候选提示仅可来自：明确 individual、姓名与用户确认对象匹配、complete、明确且匹配核算期间、可解析金额、无阻断性核对项。群体合计、部分支付和不明作用域仍展示出处，不进入个人完整总额提示。所有候选均不授予计算权限；用户依旧须核实并独立输入完整总额。规则对自然语言的校验有限，不宣称字面通过等于语义正确。

完整性字段只描述应付/已付工资总额范围：date、rate、arrears、award、other_money 统一 not_applicable；due_total/paid_total 明确累计完整才 complete，未明 unknown，明确部分 partial；payment 明确单笔/预支/部分用 partial，仅泛称支付且无全额依据用 unknown。原文若无税前/实发依据不虚构口径，用户金额确认仍单独核实该项。

## 推理与运行

沿用已经验证的 `scripts/fact-runtime-v2.py`、MLX 内存 helper 和 DeepSeek 传输 helper。Qwen为同一Qwen3-32B-4bit revision，no adapter、temperature 0、seed123、non-thinking、4096输出/12288总tokens、prefill128、4bit KV；每材料独立进程，wired20GiB、allocator guideline24GiB、cache512MiB，原warning10秒/critical/swap增长4GiB/600秒保护不变。权重验证与包版本记录在 model-identity.json。

DeepSeek为deepseek-v4-pro、non-thinking、temperature0、4096输出，无专用JSON mode；共用同一提示与消费适配。临时使用既有测试机出口，TLS与密钥留本机，官方域名/证书验证、不重定向。每材料最多一个POST；仅发送前最多3次连接尝试，socket120秒、绝对请求180秒、整批2400秒，单批预算上界2美元。响应成功后即终局，格式差/语义错/length不重试；全部错误与未运行项留分母。开发与正式各自保留，禁止拼接。

冻结后依次执行规则、Qwen和DeepSeek，后两者可同时运行；高内存构建与Qwen串行。结果落入不允许覆盖的新目录。输入prompt只含blocks，不含文件名、内部source标识、金标或先前输出。

## 指标与判断

分别报告计划材料、返回、正常stop、原生JSON、经有限适配协议有效、逐项引用/字段拒绝、待核对项、完全正确材料。未完成的输出不计入接受事实。全部后端固定以全体留出金标数作召回分母，一对一最大匹配防止重复抬分。

basic比较kind、meaning、规范值，费率另比较rateUnit；strict再比较subject、scope、period、completeness和assertion。规范值只使用代码预定义的金额解析；不能以金标决定归一化。日期按原文或运行前列明的备选匹配。保留TP/FP/FN及逐题配对，不只给总体F1。

重点混淆诊断：先消耗strict正确匹配，再对剩余具有相同kind和值且双方对应唯一的预测/金标列出群体被写个人、部分付款被写完整已付、签约被写工作/履行期间；重复同值无法唯一定位时标ambiguous，不强指混淆。报告原始可解析候选与经过程序校验候选两层，拒绝了错误不等于模型学会；漏提不能冒充零错误。该诊断是有限、可复算的错误定位，非危险计算发生率。逐项待核对提示另报，不因保守词法提示存在就将语义完全匹配判错。

新任务schema与v4不同，不能直接用两轮F1差值声称效果提升。比较结论仅适用于同一新留出集的Qwen与DeepSeek。先改流程或定义的问题单列；在新材料仍重复、标签明确的残余语义错误才进入未来LoRA候选清单。本轮没有训练收益证据。
