# v7 首跑前运行协议

目标：先修 Issue #42 的确定性金额表示、无金额候选、标注边界和同额不同事件评分，再在全新、按案件隔离的公开材料上比较窄规则、Qwen3-32B-4bit 与 DeepSeek。没有训练、adapter 或生产部署。新PR不自动继承前一轮三个PR的合并授权。

两项交付按依赖推进：解析/源文防御/事件评分/标注约定PR在前；新独立数据、冻结回执、首次输出、逐层结果和独立审查PR在后。旧实验全部保持原样，不能将旧结果重评分后覆盖为“提升”。新集分数与v6仅作不同样本的描述，不形成因果改善结论。

数据作者准备3份开发材料与12份留出材料；另一位Agent在首跑前复核来源、案件隔离、原文和标签。主实现者在冻结前只使用开发材料与聚合信息，不查看留出标签或具体内容。标签性质始终为非专家暂定参考；用户、真实案件及法律专家业务验收分别待办。

相同源文、同一提示、相同协议供三路使用，输入仅材料块，不含标签/事件/评分诊断。每材料首个请求和输出保留；不因低分、空数组、非法JSON、length或协议拒收重投。传输未发送前的有限连接重试与已发送后不可重投分别记录。运行目录只追加，冻结后拒绝覆盖；任何补跑使用另名并与首轮分开。

沿用已有受控本机Qwen runtime（每材料独立进程、温度0、输出上限4096、总token上限12288及内存监测），DeepSeek用官方接口、同输出上限与既有单材料超时/有限连接重试。正式身份、可用性和定价已于2026-10-18实际核验，见 model-identity.json、api-models-preflight.json、runtime-policy.json：官方接口 GET /models 返回200；DeepSeek仍以峰值未缓存输入1.32、输出3.96美元/百万tokens保守预留，开发和留出累计预算上界2美元。资源冲突时排队，不并发启动多个MLX进程，不改变系统网络/全局配置。

报告同时列首次raw、协议accepted及生产防御诊断；固定全部材料和事实分母，记录缺失、失败、空结果、schema拒收、证据歧义。独立复算匹配/汇总并对原始输出逐案区分程序问题、非专家标签争议与明确语义错误；不把strict F1全部损失直接当训练样本。

正式运行前生成 freeze.json 并执行 verify.mjs --preflight；首跑后不修改已冻结协议。开发集3份可先进行运行就绪检查，留出集12份只运行一次；若开发结果未用于修订提示或标签，明确记录。结构化输出决策：本轮保持11字段协议与普通文本JSON提示，在提示中增加完整date示例，不自动补缺字段，不新增JSON mode或约束解码器。其独立效果需要另一轮冻结对照，不能归因于本轮多项共同修改。
