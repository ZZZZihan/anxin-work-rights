结论：点名分钟、合法角分、时间与范围交接、传统圓费率路径的对照通过；另发现分之被角分 token 吞入后可泄漏精确金额，已立即报告 ROOT，等待其独立修复。

本次使用从 CODE 当前未提交版本捕获的隔离源码；具体五文件哈希在 `reviewed-source-snapshot.json`。本人未参与这三处 ROOT money/currency/source 实现，未修改 CODE。新 probe 107 项：82 PASS、25 FAIL。25 个失败全部属于以下同一族，不是25个独立缺陷。

- `1000元5分之一` 的完整值不可用；裁剪 value/quote 为 `1000元5分` 后，完整引用规范化、新 runtime 原 source 守护、强制历史精确值读时守护均仍给 `1000.05`。
- `一千元五分之factor`、`一千元五分之α`、`一千元五分之` 等完整值本身也会给 `1000.05`。
- ROOT 已确认自行增加有限分之词界；合法 `1000元5分之后支付` 是必须保留的邻近对照。

源码核查：新的 RANGE_AFTER 要求第二货币端点，NUMERIC_AFTER 对不完整端点保守降级；TIME_AFTER 仅在直接有限日期/时长语法上绕过旧 legacy 的 range 状态。新角分 guard 在定位 token 后仅以检测副本确认词界，原始 UTF-16 锚点和返回 code-point span 均继续来自原文。传统圓被加入裸数字的后置单位/费率与截断检测，未发现本组传统率测试误放。

覆盖界限：这是一组无模型合成的 parser/候选/source/runtime/历史测试，没有真实 HTTP、模型输出、确认流程或生产计算验收。OCR 跨块只要“分”与“钟”间没有可见句标便会保守拒绝；对缺少标点的另一事件人名“钟某”不声称能做语义识别。有限词表不声称穷尽。
