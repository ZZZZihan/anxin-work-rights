# 地区展示案例

这组静态素材以天津为主，兼顾北京和南京：天津4案、北京2案、南京2案。每案包含2份TXT材料、1份文书草稿和1个咨询问题；八个独立当事人的场景由林晓展示账户统一管理。

人物、公司、日期、金额、材料及协商结果均为原创虚构。官方公开案例用于确定争议结构和证据整理方向，素材不是原案卷宗，不代表官方审核或用户真实档案。

## 文件与复用

- `content.json`：案件业务字段、材料正文、文书字段、问题及来源元数据。
- `materials/<case.key>/`：与JSON正文逐字节相同的UTF-8 TXT文件。
- `checksums.json`：JSON文件、材料字节、文书字段及问题的SHA-256。文书字段使用按键排序、无额外空格的UTF-8 JSON计算。

这些文件不被应用启动、构建或部署自动导入，不改变现有运行数据。使用素材时应先校验内容，再由明确的数据导入流程处理。

`profile`、`provenance`以及每案的`key`、`region`、`applicant`、`sourceRefs`属于素材元数据，仅供资料说明，不发送到业务API或页面。案件创建只取`company`、`type`、`amount`、`location`、`description`、`nextAction`、`deadline`；`currentStep`另按现有接口更新。材料、文书和问题分别使用各自接口字段，不能将整份JSON作为创建请求。

## 改编边界

年休假分别核对既往连续工作与新单位当年折算。人事续约场景保留明确职责、知晓制度及实际授权经办事实，不推广为所有人事人员的统一结论。线上加班区分安排的实质劳动和零散消息，金额按原创工时草案核算。主播场景依据实际自主程度与管理方式，不凭职业或协议名称认定关系。

家政的关系确认不等于已经裁决补缴社保；孕期调岗审查理由、条件和协商，不表述为绝对禁止调岗。普通厨师是否接触受保护秘密须具体核对，不能只凭职业或补偿情况判断。南京用工场景只围绕劳动及派遣关系整理，不扩写成欠薪、工伤或所有债务的连带赔付结果。

文书为当事人整理或申请草稿，不制作官方裁判书、公章、真实案号或身份号码。两案的完成状态只表示原创场景中的私人协商结清，金额和结果均不当作官方原案结论。原文只确定市级地区的，不增编原案区级地点。
